# TU TIÊN CHÂN GIỚI

Game tu tiên nhàn rỗi bằng HTML/CSS/JavaScript thuần, không cần cài đặt thư viện, API key hay dịch vụ trả phí.

## Chơi thử trên máy
Mở file `index.html` bằng trình duyệt hiện đại.

## Đưa game lên mạng miễn phí bằng GitHub Pages
1. Mở **Settings** của repository.
2. Chọn **Pages** ở thanh bên.
3. Trong **Build and deployment**, chọn **Deploy from a branch**.
4. Chọn branch **main** và thư mục **/(root)**, rồi bấm **Save**.
5. Đợi GitHub triển khai xong. Trang game sẽ có địa chỉ dạng `https://khucminhhaibhu-creator.github.io/tu-tien-chan-gioi/`.

## Tính năng trong bản demo
- Chọn nam tu/nữ tu, đặt đạo hiệu và chọn linh căn.
- Tu luyện, tích lũy tu vi, lên tầng và thử đột phá cảnh giới.
- Bái một trong sáu sư tôn, gia nhập tông môn.
- Lịch luyện ở ba khu vực, chiến đấu mô phỏng, nhận linh thạch và vật phẩm.
- Túi đồ, phúc lợi ngày và nhật ký tu tiên.
- Tự lưu tiến trình trong localStorage của trình duyệt hiện tại.

## Lưu ý
Đây là bản demo chạy phía trình duyệt. Tiến trình được lưu trên thiết bị/trình duyệt đang chơi, chưa đồng bộ giữa nhiều thiết bị và chưa có tài khoản đăng nhập hay máy chủ nhiều người chơi. Nếu xóa dữ liệu trình duyệt, tiến trình có thể mất.
